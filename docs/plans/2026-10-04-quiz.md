# Plan: Quiz — isolated (Josh: "build some quiz stuff too. Just keep it isolated")

Status: draft → Fable review → Fable build.

## Goal
A standalone quiz page (not linked from the app yet) for retrieval practice + ear/sight drills, so session-start quizzes (memory: session-start-theory-quiz; docs: quizzes.md protocol) can run in the browser/iPad instead of only in chat.

## Isolation
- New page `quiz.html` + `src/quiz/*.js` (own entry `src/quiz/main.js`), own tests `tests/quiz.test.mjs` (add to tools/run-tests.mjs). Reuses ONLY pure, layer-0/2 modules (theory spelling, midi, the synth voice used for previews if it can be imported without app boot — else a tiny WebAudio tone in src/quiz/). No imports from ui/, session/, ask/. Not in the app's menus, not in the SW precache list (or precached but unlinked — reviewer decides), not in the package for iPad yet.
- Integration points listed in docs/quiz.md (a View ▾ entry, a help-sheet entry, AI "quiz me" hook) — not wired.

## Content
1. Bank mode: parse quizzes.md (headings/questions; it has NO answers on purpose). Show one question at a time; Josh answers in his head/aloud or types; self-grade (got it / shaky / missed). Spaced repetition (Leitner boxes) stored device-locally (localStorage key ff1roll-quiz-*). Never invents answers.
2. Drills (generated, general theory — never about Josh's own songs' analyses): interval by sight (staff/notes) and by ear, chord quality by ear (maj/min/dim/aug/7ths), scale-degree singing check, key-signature recall, note spelling in a key. Difficulty steps; streaks.
3. Learning-mode respect: drills are generic exercises; nothing reads his songs' annotations or names chords/keys in his music.

## UI
Dark theme matching css/app.css tokens (link css/app.css or a small quiz.css reusing tokens), touch-first big buttons, iPad + phone widths, no native dialogs.

## Tests
Parser on quizzes.md (counts, sections), SRS scheduling, drill generators (valid intervals/spellings, uniform coverage), answer checking, persistence wrappers (try/catch).

## Verification
npm test, smoke unaffected, quiz.html loads standalone in a browser with no console errors (main session checks), check.mjs clean (new files obey rules).

## Out of scope
Linking into the app; AI-graded answers; syncing progress across devices.
