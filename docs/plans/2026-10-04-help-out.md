# Plan: move the help text out of index.html (Josh: "Sure, move the help text out.")

Status: draft → Fable review → Fable build.

## Goal
index.html keeps only the help SHEET frame (overlay, header, tabs, close); the ~420 lines of help content (the per-tab sections: dt/dd entries) live in `help/help.html` (an HTML fragment), loaded the first time Help opens, cached offline.

## Facts (verify)
- index.html `#helpsheet` (tabs + `.hsec` sections); opened in src/ui/notes.js (~L175 showHelpTab, ~L581 `helpsheet.classList.add("on")`) and from File ▾ Help; other openers? (grep `helpsheet`, `showHelpTab`, deep links into help sections, the AI or tours that read help text).
- tools/build_help.mjs builds HELP.md from index.html's `#helpsheet` region (slice to `id="filesheet"`).
- tests/night-roll.test.mjs ~L2771 FEATURES drift check reads index.html's help region; other tests read help text (grep `helpsheet`, `hsec`, `HELP.md`).
- css/app.css styles `.sheet.help .hsec…` — unchanged.
- sw.js precache / network-first routes; tools/package.mjs copies listed dirs + guards.

## Design
- `help/help.html`: the exact content that today sits inside the sheet's scroll body (all `.hsec` sections), byte-identical (verify with a diff of the extracted block).
- Loader in src/ui (the module that owns Help): `ensureHelpLoaded()` — fetch once, inject into the sheet body, then run whatever setup showHelpTab needs; Help opens immediately with a small "Loading help…" line if the fetch is slow; offline served from the SW cache; on failure show a one-line error in the sheet (no native dialog).
- Every path that opens help (incl. deep links to a section) awaits ensureHelpLoaded().
- sw.js: precache help/help.html; route help/ like css/ (network-first, revalidate); bump SW_VERSION.
- tools/package.mjs: copy help/; guard that help/help.html exists.
- tools/build_help.mjs + the FEATURES drift test + any help-text tests read help/help.html (shared helper, e.g. tests/harness.mjs `helpSource()`); appSource() includes it so greps keep working.
- Docs: CLAUDE.md shipping checklist step 2 ("Help sheet entry in index.html (#helpsheet…)") → help/help.html; NIGHT-ROLL.md; HELP.md regenerated (content must be identical).

## Tests
Byte-identity of the moved content; ensureHelpLoaded fetch-once + injection (vm with a stub fetch); every opener path loads before showing; offline/failure message; pwa/package tests: precached, packaged, routed; FEATURES drift reads the new file; HELP.md unchanged after regeneration.

## Verification
npm test (only ps2-real/instruments may fail locally), smoke, package.mjs, check.mjs; main session: browser — open Help (each tab), deep-link a section, airplane-mode reopen on iPad.

## Out of scope
Rewriting help content; moving other sheets.

### Gaps found → decisions
1. **Loading state.** `#helpbody` ships with `<p class="status">Loading
   help…</p>`; the sheet opens at once, tabs already highlight (the saved
   tab wins once content lands — `openHelp` re-runs `showHelpTab` after
   the fetch). 110 KB from the SW cache is instant; from Pages it is one
   request behind a tab-strip that already works.
2. **Failure.** fetch rejects / !ok → the body reads "Help couldn't be
   loaded (offline?). The full manual is on GitHub: HELP.md ↗" (the same
   link the footer row has) and `S.helpLoad` resets to null so the NEXT
   open retries. No native dialog, no setInfo spam.
3. **Offline.** Precached (install) + network-first with cache fallback
   (route). An install that predates nr-v34 gets the file on its next
   online activate. Airplane-mode on a fresh clone with no SW (dev server,
   file://): the failure line above.
4. **Byte-identity proof.** `help/help.html` = one leading HTML comment
   (purpose + "HELP.md is generated from this") + "\n" + the verbatim
   L850–1021 block. Proof recorded in the commit: `sha256(sed -n 850,1021p
   HEAD~:index.html) == sha256(tail -n +N help/help.html)`. Ongoing guard:
   a test asserts index.html has no `.hsec` left, help.html's `data-hsec`
   set equals `#helptabs`' `data-hs` set, and `#helpbody` exists.
