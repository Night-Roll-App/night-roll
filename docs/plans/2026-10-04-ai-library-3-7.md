## Risks
- Storage-key drift = chat loss. The step-4 fixture is the guard; the builder also runs the harness against a copy of a real device's keys if Josh exports one (optional).
- Learning leaks: `RULE_LEARNING`, `askSessionName#normal`, `askModeLine`, the context block's "key state: not set" line all stay in src/ask/context.js; the library never sees `appMode()`.
- SW caching: `AI_LIB` is part of the cache name — each sync turns the cache over automatically.
- Name collisions: library exports are `ai*`, Night Roll's are `ask*`; check.mjs rule 6 and the harness's bare-name resolution surface a clash as a failing test.
- Library tags are local until the main session pushes them: never merge a Night Roll commit whose vendor/ai/VERSION names a tag the remote lacks.
