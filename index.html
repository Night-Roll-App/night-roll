NIGHT // ROLL

The chiptune DAW that teaches you composition — a piano roll and an engraved score over one timeline, authentic 2A03 chip audio, and an annotation layer that lives with the notes. This site is where it was built: by studying the Final Fantasy I soundtrack, captured note-for-note from the actual NES sound chip.

House rule: keys, meters, and chords are the analyst's discoveries. The app displays evidence and records verdicts — it never decides them for you.

Sounds: FluidR3_GM by Frank Wen (MIT), via Benjamin Gleitzman's midi-js-soundfonts (MIT). Notation: VexFlow (MIT). Night Roll itself: PolyForm Noncommercial 1.0.0 — free for personal and noncommercial use; selling or republishing it is not permitted.

TRANSPOSE

Chromatic moves everything blindly by semitones. In key moves each note to the next scale degree of the declared key — a "whole step up that stays in the key," so some notes move 1 and some move 2. One ⟲ per tap.

INSERT TIME

Opens a gap: everything from the insert point onward slides right; a section or chord that starts before and is still open at the point stretches instead; one that ends exactly at the point stays put. Notes, sections, chords, the loop — all carried. One undo undoes it.

DELETE BARS

Closes a gap: a note starting inside is removed, one sustaining across the cut is clipped there, everything after slides left to fill it. Notes, sections, chords, the loop — all carried; one anchored inside the deleted bars moves to the cut point instead of being lost, and one straddling it shrinks. One undo undoes it.

ANALYZE

✦ ANNOTATE THIS SONG — AI ESTIMATES

Asks the AI model from Settings for estimates of this song's sections, chords and key — read from the notes plus computed facts (which bars repeat, how the bass moves) — and writes them as annotations tagged ✦ AI. Your own annotations are never overwritten: an estimate that overlaps one of yours is skipped. One undo takes a run back; Clear AI annotations removes every tagged one at once. Long songs go in bar windows and merge. Unsynced until you Publish, like any annotation.

SHAPE

The loudness inside each selected note, on one sound — no new attack. Velocity stays the start; the shape scales to each note's length and moves with velocity. Flat clears it. Drag a point in the velocity lane to fine-tune one note. One undo undoes it.

DIVIDE INTO

Each selected note becomes N equal notes — pitch, velocity, and total length unchanged. 3 on a half note = quarter-note triplets; 3 on a quarter = eighth triplets; 6 on two beats = a run of six. One undo undoes it.

QUANTIZE

Snaps each selected note's start to the current grid (the same grid Move and Pencil use — 16ths, triplet steps with a T duration active, or 32nds once the song has any). 100% lands exactly on the line; 75%/50% is a softer nudge, partway there — good for a raw take that's close but not glued to the grid. One undo undoes the whole selection.

MIDI
.mid / .midi / .smf / .kar / .rmi (even RIFF-wrapped) → a song — Keep local (this device only) or Create album for several at once.
NES
The .nsf, plus its .m3u if the rip has one (names the tracks) — or drop the .m3u on its own, later, to name an already-open album's tracks. Not supported: expansion-chip games (VRC6, VRC7, FDS, MMC5, Namco 163, Sunsoft 5B) — refused by name, "expansion sound chip <names> not supported". Captures run in the background (⏳ Jobs) — this window can be closed once one starts.
Game Boy
The .gbs, plus its .m3u, same rule as NES — and the same background capture.
Super NES
Every .spc of the album, picked together.
Genesis
.vgm / .vgz. Synth voices only — no console-audio render yet.
PlayStation
Every .minipsf plus the one .psflib, picked together. Reads Sony's standard driver (SEQ/VAB) and Square's AKAO (Final Fantasy VII/VIII/IX, Chrono Cross) — both play the console's own audio.
PlayStation 2
Every .minipsf2/.psf2 plus the one .psf2lib, picked together. Reads Sony's standard driver (SQ/HD/BD) and Square Enix's own (BGM/WD — Final Fantasy X) — both play the console's own audio. Streamed-audio rips (Ico, XIII) are refused: "this is streamed audio, not note data — Night Roll reads sequence data (notes), not pre-rendered streams".
Nintendo 64
The .miniusf files plus the one .usflib.
SoundFont
One .sf2 — its presets become track voices, not tied to a song.
New song from a recording
One .wav / .mp3 / .m4a / .aif / .flac → a new song — Untitled until Save, 4/4 at 120 bpm; ♩ Tempo from this take afterwards reads the real tempo off the clip.
Drop files anywhere on this panel, or use a section's Choose files… above.

For chasing a problem with Claude. Off, only real problems raise the ⚠ chip; on, the ⚠ sheet also shows what the audio engine measured, marked [debug].
Chip stream
Experimental (docs/streamed-render-plan.md): console audio for a PlayStation/PlayStation 2 song arrives a couple of seconds at a time instead of rendering the whole song up front — the fix for a big song (FFX "Challenge") crashing the iPad's memory. Off: today's whole-render behavior, unchanged. On: stream mode for every song whose chip supports it; any failure falls back to the whole render for that song. Auto (default): streams only a song that would otherwise have to downgrade quality (mono, or a lower sample rate) or refuse to fit this device's memory — every other PS1/PS2 song, and every other console, plays the unchanged whole render.
On: the Pencil places, grabs and moves notes the moment it touches — no hold; fingers still hold to grab and swipe to scroll. Off: the Pencil behaves like a finger.
Off (the DAW way): selecting a note leaves the playhead where it is, so Space plays from where you were. + Note still anchors at the note you tapped.
Off (the DAW way — Logic, GarageBand, Cubasis): ● Record keeps exactly what you played, on- or off-grid. On: every key restores today's behavior, snapping starts and durations to the move grid as you play. Either way, Q Quantize straightens a take afterward, undoably.
Text size
Scales Night Roll's own text, not its layout — buttons, rows and the canvas stay the same size, only the type inside grows. An iPhone/iPad's Settings → Accessibility → Display & Text Size → Larger Text already carries through on its own (Safari's Dynamic Type); use this for a browser that doesn't, or to go further.
