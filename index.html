NIGHT // ROLL

The chiptune DAW that teaches you composition — a piano roll and an engraved score over one timeline, authentic 2A03 chip audio, and an annotation layer that lives with the notes. This site is where it was built: by studying the Final Fantasy I soundtrack, captured note-for-note from the actual NES sound chip.

House rule: keys, meters, and chords are the analyst's discoveries. The app displays evidence and records verdicts — it never decides them for you.

NIGHT ROLL — WHAT YOU CAN DO

🎓 Learning mode
Tap it in View ▾ → 🎓 Learning mode (or Settings → Other) to switch off. On (the default on a device that's been used for analysis before): meter, key and chord names stay undeclared until you work them out yourself — a lasso still lists the notes, Chord? stays hidden so you name it first, and the LCD reads the usual "4/4?" / "C?" until you've earned the real answer. Off (Normal): lasso'd chords name themselves, an unset meter/key shows a labelled estimate (LCD "Gm~", the key picker's "estimated — tap to set") instead of the plain default — estimates are never written as a real annotation until you tap "Set this key". The toggle is one device-global switch, not per song; nothing in the header names which one you're in any more (chrome density follow-up, 2026-10-01 pm: the gold "🎓 Learning" header tag is gone — Josh's own ruling, after using the first chrome density pass) — check Settings → Other or View ▾ → Mode.
Analyze ▸
Normal mode only (View ▾ → Analyze ▸ — the item is absent in Learning, same as every other Learning hiding place). Toggling it on draws a dashed "analysis" layer on the roll, below the real section/chord bands: a per-bar chord name inferred from every harmony track (drums excluded, same reader the Bassist's internal sketch uses) plus a whole-song key estimate — labelled as an estimate, never written anywhere until you say so. Tap a dashed band to open it: Adopt writes that one chord/key as a real annotation through the usual write path (one undo undoes it); a chord band also offers Adopt all chords. Off by default every session; switching to Learning turns it off immediately, mid-computation or not.
Compare with repo
View → Compare with repo (or the Compare button on a song's "music edited" line in the Publish sheet) fetches the song's published copy and outlines every difference on the roll: gold = a note only in your version, red = a note only in the published copy, both on a note whose length or velocity changed; dashed outlines mark notes that are not in the version you are hearing. The bar above the roll counts them and its button swaps which version plays — hear the published copy swaps its notes in (the song is read-only until you swap back; nothing is written, your draft stays yours), hear your version swaps them back. ✕ on the bar leaves compare. Works on your own songs that have been published; turn a chop off first.
▾ Hide controls
The ▾ at the footer's left folds the bottom controls (edit row + footer) away so small screens show music instead of buttons — a floating ▴ brings them back. Phones start folded automatically; your explicit choice is remembered per device.
Closing a sheet
Every sheet closes three ways: tap the dimmed area outside it, tap the ✕ pinned to its top-right (it stays put while a long sheet scrolls, so the notes list never makes you scroll to the bottom to get out), or press Esc. Esc closes the topmost one, so stacked sheets unstack one at a time. Saving or sending closes the sheet for you. The only exception is a confirm box — it asked a question, so it waits for an answer.
𝄞 Score / Roll
Switch between piano roll and engraved sheet music. Same timeline, same everything else. Your choice is remembered.
Drag / pinch
One finger pans; two fingers zoom — spread horizontally to stretch time, vertically to grow/shrink the pitch rows (roll only). Two fingers moving TOGETHER pan — and that works with pencil or select armed; anything the first finger started is rolled back the instant the second finger lands. With an Apple Pencil (or one finger), hold to grab: dwell about a quarter second on a note before it drags, and the pencil tool only places a note on a clean tap or a dwell — a fast passing stroke always PANS, so sweeping across the song never moves a note or plants a stray one. A mouse grabs instantly (pressing a mouse button is already deliberate); the Apple Pencil can too — Settings → Other → "Apple Pencil draws and grabs at once" (off by default: with it on, a Pencil swipe that starts on a note moves the note instead of scrolling). Songs open fitted to the screen. In score view, scroll fully left to see the clefs and key signature.
Roll zoom-out limit
Each song remembers its zoom and where you were scrolled to on this device — reopening it, or a restart, comes back to the same view (a song you have never opened here starts fitted). Dragging can still push the song further left than that — up to 16 empty bars past its end, room to write the next part. Pinch-out stops once the whole song is in view — per axis: when every bar fits, further pinch-out only reveals pitch; when every note is visible — plus a few rows of breathing room above and below, so the top notes never sit against the ruler — it stops. Opening a song lands exactly on this limit.
Score zoom limit
The score stops zooming out where its busiest bar would overflow — engraved notes can't shrink. Mute dense tracks to zoom out further, or use the Roll for the bird's-eye view.
VoiceOver (first pass)
The roll/score/tracks canvas is a screen reader's one blind spot in Night Roll — this is a first pass, not a full non-visual editor. Every icon-only button (Back to start, Play, Metronome, gear, AI, Screenshot, Undo, Redo, Copy, Paste, Cut, Divide, track chip M/S/H, mixer strips, sheet ✕s…) has a real label, and toggles report their on/off state. An offscreen strip announces play/stop, the bar.beat where playback stopped, and the selected note(s) or chord — always the SAME words the footer status line already shows, never more (Learning mode's rule holds here too: nothing is spoken that the screen doesn't already say). The canvas itself carries a label naming the open song, which view, the visible bars, and the track count. Every sheet is a labelled dialog; opening one moves focus in, closing it gives focus back to whatever you opened it from. Tab reaches every control, with a visible focus ring.
Play / ■ Stop
NES-style voices; drum tracks get a real kit. Songs loop at their final bar forever (album play, below, is what ends them). While a song is still loading its sound — the console's voice, game or SoundFont instruments, a recording — Play shows 42% and waits; tap it then and it plays by itself the moment the sound is ready (tap again to cancel); a load that fails lets you play anyway and says why.
Playing in the background
In the installed iPad app, music keeps playing when you leave the app or lock the screen: start a song or an album, then switch away. Come back to see where it is.
Play album
In File → Open…, every album has a Play album row at the top (it starts from the song you have open when that song is in the album). The album plays straight through like a record — each song gets its intro plus two passes of its loop, fades, and the next one loads (the console's own sound is waited for while it renders) — and wraps around to the first song forever. While it plays, a strip under the transport shows 3/19, the song, and what's next, with Prev, Next, and ✕ to leave. Play, ■, Back to start and Space work on the current song exactly as always (■ just pauses the album; Play picks it back up). Picking another song, Record, or Download audio also leaves. No dialog will interrupt a run: a song with a newer save on the repo plays from this device's draft and says so. Editing while it plays is fine. Keep the screen on — locking the iPad pauses it, and unlocking picks up where it stopped. While a run is on, the address bar carries it too (?album=) — opening that link reopens with the strip up, run armed, same song selected, and nothing playing yet; the first Play plays it as an album pass, same as picking Play album.
Game order / A–Z
Tap an album's song list (Open… or File → Open) and, when that album's soundtrack position is known, a small Game order | A–Z switch sits at the top: Game order plays the songs in the same order the original game's soundtrack does (multi-disc sets go disc then track; a song with no known position sorts after the numbered ones, alphabetically); A–Z is plain alphabetical. One device-wide setting, remembered across albums. The switch only appears on an album that HAS a soundtrack position for its songs — most capture albums do (51 so far), a few don't yet (no rip's playlist to read the order from). Play album and its Prev / Next always walk whichever order the list is currently showing — switch it and the next song picked follows the new order too.
⏱ Metronome
Tap ⏱ to turn the click on or off; the gear beside it opens the settings. Any meter (1–12 over 2/4/8/16 — bpm counts the denominator beat), tap each beat cell to cycle accent → normal → silent, subdivisions in 2/3/4, slider or tap-tempo. Three modes: free-running (its own clock); follow song — clicks ride the song's own grid, phase-perfect on the declared meter through tempo changes, speed slider, and loops (with the song stopped it still clicks, at the song's tempo where the cursor sits); trial meter — click a meter of YOUR choosing over the real music to A/B candidates by ear (the "shift accents" ‹ › slides the pattern's starting beat, since a right meter can sit offset). Settings stick.
Count-in
Optional one-bar click lead-in. Playing counts in only from bar 1 beat 1 — never mid-song, never when the song loops back around; recording counts in from wherever it starts, so a punch-in at bar 17 gets its bar of clicks too.
Back to start
Back to bar 1 — or, when the ruler has a selection (cycling or parked), back to the selection's start, with the view scrolled there. Return does the same.
Speed slider
25–200% of the song's own tempo, for close listening or instrument practice — pitch stays true; only time stretches. Applies when you let go; keeps its setting across songs. A 100% button appears whenever you're off native — tap to snap back.
Scroll while playing
Scrolling away suspends the auto-follow camera so you can study any spot; it latches back on when the playhead reaches what you're looking at.
▤ Tracks view
The arrangement view (the view drop-up bottom-left in the footer — Roll / Tracks / 𝄞 Score, its label naming the CURRENT view; also in View ▾): one lane per track, its notes drawn as a thumbnail (each lane scaled to its own range), with the track's color dot, name, M/S, and a volume fader in the lane header — the fader saves as the same vol= annotation as the voice menu's. Tap a note to select it (it sounds); lasso a box and it selects by TIME across every lane it touches — cross-track selection in one gesture. Hold-to-grab a selected note and drag: sideways moves it in time (bar-magnet-free, 16th snap), and dragging up or down carries the whole selection to another lane — pitch kept, one undo undoes it, drums and melodic lanes never mix. Dragging shows a ghost until you release. Tap a lane's header to select that track; tap the selected track's header again for its voice & volume menu. Pencil doesn't draw here (a squeezed lane has no honest pitch) — it draws in Roll or Score; Erase works. The ruler above is the same one as always: sections, cycle, magnetic bars, the playhead triangle.
🎸 Bassist
The 🎸 beside Drummer (behind More, or Edit ▾ → Bassist…) generates a bassline for the range onto a track you pick (defaults to a NEW bass track unless an empty one exists — it never silently overwrites your notes; the status line says exactly what it replaces). PITCHES COME FROM YOUR DECLARED CHORDS — chord tones, slash basses honored (C♯/F walks to the F), N.C. bars pedal the key root; gaps ride the last chord. With ONLY a melody and no chords, it sketches the melody's harmony internally (duration-weighted, strong beats count more) and plays bass under that sketch — the sketch is never shown or written anywhere, and different seeds read the melody differently, which is the idea machine — declared chords always win bar-by-bar, inference only fills the unannotated gaps. The bass PLAYS THROUGH your Break sections (a Break is bass-alone by your own device). Styles: chug (root 8ths), pump (root–fifth), arp (chord tones cycling), walk (approach notes INTO each coming chord — the leading-tone move, mechanized), riff (rhythm copied from the follow source: the kick, any track, or the chord changes). busy 1–5, octave 1–3, strictly monophonic (NES-legal), same take chips / one-undo replace / same-label-sections-restate contract as the Drummer.
Insert bars
Edit ▾ → Insert bars… opens a gap anywhere in the song: pick the spot (bar + beat, decimals fine), how much (a count of bars, beats, or 16ths), and Insert. Everything from that point onward — notes, sections, chords, keys, the loop point — slides right together. A section that starts before the point and is still open there STRETCHES to span the gap; one that ends exactly at the point stays put (stretch it yourself if you want it covering the new bars). One undo undoes the whole thing.
Delete bars
Edit ▾ → Delete bars…, right under Insert bars, closes a gap instead of opening one: pick the bar to start from (defaults to the cursor's bar) and how many to remove, and Delete. A note starting inside the deleted bars is removed; one sustaining across the cut is clipped there; everything after slides left to fill the gap — notes, sections, chords, keys, the loop point, all carried, same as Insert bars. Annotations never die: one anchored inside the deleted span moves to the cut point instead of being lost, and one straddling the cut shrinks rather than being duplicated or orphaned. The status line names what moved. One undo undoes the whole thing.
Space
Play / stop, Logic-style — anywhere except while typing in a text field. With a hardware keyboard on iPad too.
Hardware keyboard
Logic's keys: Return back to the start (or the ruler selection's start), K click on/off, C cycle on/off, R record, Q quantizes the selection, ⌘← / ⌘→ zoom out / in around the cursor. Editing: ⌘A selects every visible note, ⌘C / ⌘X / ⌘V copy, cut, paste at the playhead, ⌘D duplicates the selection right after itself (whole bars when it's longer than a beat — press again to keep repeating), ⌘Z / ⇧⌘Z undo / redo, ⌘S Save Version, arrows move, ⇧ an octave, ⌥ resizes, Delete removes.
Grid
Notes move and resize on a 16th grid, or on triplet steps while a T duration is active — and the duration chips stay visible in Select, where they are that move grid, so changing it never means a trip through Pencil. Touching a note picks up its grid automatically: grab a triplet note and moves go in triplet steps, grab a straight one and they go in 16ths; tap a chip afterwards to override. View ▾ → Grid… opens a sheet: tap a number of lines per bar (say 10) and the roll redraws instantly with that many lines in each bar — and pencil entry, note drags and resizes all SNAP to those lines. Pure view-and-snap aid: no note moves, no annotation changes, the time signature stays what it is. This is how a figure the duration buttons can't spell — ten even notes across a 4/4 bar, each 0.4 beats — becomes pencil-drag from line to line; with a grid armed, a pencil tap lays down one cell — in the roll, the fall view and the score alike — so 6 lines per bar pencils quarter-note triplets and 12 pencils eighth triplets without touching the duration chips (they dim while a grid rules, and a chip appears at the end of the row naming the grid — tap it for the sheet; opening another song turns the grid off). Set the anchor right in the sheet — bar and beat, and the beat takes decimals for sub-beat starts (2.5 = the "and" of 2, 2.25 = the second sixteenth) — and the lines run from there (14.2, say), so a figure beginning mid-bar gets its lines exactly where its notes go, continuing bar after bar on that phase across the whole song. Bar lines stay drawn for orientation but stop being snap targets while the grid is armed; a bar line falling between cells is expected, not a bug. Off returns to the meter's own grid (16ths, or triplet steps while a T duration is armed). Transient by design: set it, enter the passage, set it back.
Listener mode
Phones open as a PLAYER: the roll, the transport, the readouts, speed and volume — everything else hidden, including the section/chord bands and the notes strip (unreadably small on a phone anyway), because a shared song link is for listening, not editing. A Full app button in the header brings the whole DAW back on that device (and View ▾ → Listener mode folds it away again, on any device). Send someone a ?song= link and their phone just… plays it.
View ▾ menu
Beside Edit in the header (always there, even on locked songs) — six expanding groups, top to bottom (sub-menu follow-up, 2026-10-02, Josh: "View ▾ is too tall — make EVERY section an expanding sub-menu"): tap a group's header row (▸ closed / ▾ open) to expand it in place — opening one collapses whichever other group was open, so at most one is ever open, and the menu always starts fresh with all six closed. View (one ▸ View type row — tap to expand Roll / Tracks view / 𝄞 Score view, a radio, one ✓ at a time, the same views the footer's bottom-left view drop-up switches between; its own closed label always names the CURRENT view), Panels (Instrument panel, 💬 Notes strip, Mixer, ◂ Tracks — the windows and side panels you open beside the roll), Tools (renamed from Highlight / Readout — 8va octave numbers, find: the pitch finder, ◯5 Circle of fifths), Display (Edit toolbar, Bottom bar, ┄ Outline new notes — a dashed white outline on every note added since the song opened, off by default, this device only —, Grid…, and ▸ Section levels with −/+ steppers — shows "2 of 3"; the gutter chevron still one-tap cycles — what the roll itself shows or snaps to), Background (Jobs, Messages — its own header names a running count too; both stay in the group even when their matching footer button is hidden, so a finished job or an already-read message log is still reachable), and Mode (Analyze ▸, Compare with repo, 🎓 Learning mode, Listener mode — these change what editing, or the whole app, means; the header itself names which mode you're in). ✓ means on, visible, or current; the menu STAYS OPEN while you flip several items at once inside an open group, and closes on a tap anywhere else (or the moment an item opens its own separate sheet — Grid…, Compare, Jobs, Messages). Every item mirrors an existing button — the buttons are the fast path, the menu is the findable one. The header itself never hides, so View ▾ is always the way back; hiding the bottom bar floats the ▴ restore button bottom-left (one tap brings everything back). The old ▾ hide buttons are gone — hiding lives here now.
Speed & volume buttons
The speed slider folded into a percentage button — tap to open the slider, tap anywhere else and it folds back (the reset chip appears when off-native). Beside it, the volume button is a master volume the same way: tap, slide (10–200%), tap away; the setting sticks per device and the button shows the number when it's not 100%.
LCD readout
Beside Play, Logic-style: live bar and beat (counted in the declared meter's beats), the tempo at the cursor from the song's own tempo map (scaled by the speed slider), and the declared meter and key. Undeclared stays honest: meter reads "4/4?", key reads "C?" (the display default), a stored tonic reads "B♭?". On your own songs the tempo segment is tappable too — it opens a Tempo change annotation ("tempo: 120" at a bar/beat; the map applies from there, so mid-song tempo changes work; Save writes the full map into the .mid). On analyzed songs the same annotation is an OBSERVATION — it records that the music changes tempo there and leaves playback untouched (the capture's timing is measured fact). Every readout is a door to the song's OPENING value — always bar 1, wherever the cursor is: tap the tempo, the meter or the key to open the one at bar 1 (or declare it there); a change partway through goes in with + Note — a stored partial opens its own note with the tonic already filled.
Blue cursor
Play starts here. Tap the bar ruler to place it, or drag its handle (triangle under the ruler). Tapping a note selects it without moving the cursor, the DAW way, so Space still plays from where you were; + Note anchors at the note you tapped. (Settings → Other brings back tap-to-move.)

Track chips (top)
When the screen gets narrow (say the AI window is docked wide), the chips move to their own row under Play and the LCD instead of being cut off, and come back beside them when there's room again. One tap each, any time, even mid-playback, and the song remembers them (saved with its annotations, like voice and volume). Tap the selected chip AGAIN for the voice & color menu, organized by family: NES / waves (pulses, triangle, sine, saw; auto = the classic assignment, and its menu row SAYS what it resolves to for this track — "auto: pulse 50%", or "auto: chip" when the game's own sound is available), then real sampled instruments — Keys & mallets (piano, electric piano, harpsichord, celesta, music box, vibraphone, marimba, glockenspiel), Guitar & bass, Strings (solo violin/viola/cello/contrabass, the full section, pizzicato, harp), Winds (flute, piccolo, clarinet, oboe, saxes), Brass (trumpet, trombone, french horn, tuba, section), Organ & choir — 36 FluidR3 soundfont instruments, each fetched only when a track uses it and cached after, and loudness-matched to the chip voices automatically — a violin at the same velocity as a pulse now sits at the same level, so velocity stays a musical choice instead of a mixing workaround. On your own songs the menu also RENAMES the track (type a name, tap Rename): voice, color, and volume settings migrate with it, and Save bakes the name into the .mid. Name a track "drums" (or "kit"/"percussion") and it becomes a drum track. Both save as a normal synced annotation ("track: pulse1 voice=piano") — playback and display only, the MIDI is never touched. Mixer window
Tap View ▾ → Mixer (hardware key X, Logic's mixer key, outside a text field) for a DAW-style mixer: one strip per track, side by side, scrolling sideways inside its own window if there are more than fit — the page itself never scrolls sideways. Each strip is the color dot and name, M / S / H (same as the track chips), a vertical volume fader and a live level meter beside it, and a pan slider below — every change writes the same track: annotation as the voice & color menu's fader and pan, so it's one undo step and it sticks. A MASTER strip at the end is the same volume control the header has. Drag a strip by its name to reorder it — track order follows the .mid, so this changes playback/export order too (on your own songs only; a capture's order shows read-only); dragging is one undo step that puts every track back exactly where it was, annotations (voice/color/mute/solo) stay with the track by name regardless of where it moves. The meters cost nothing while the Mixer is closed — they only start running once it's open.
Tap a note
Inspector shows pitch, bar & beat (counted 1e&a), length, velocity, track — and plays it, in Roll, Score and Tracks alike. That includes chip songs: during playback the console render IS the track's sound, so per-note synthesis is suppressed to avoid doubling, but a tap has nothing to double and sounds the game's own instrument instead, wherever it can. On PlayStation/N64 the worker renders that one note fresh through the game's own instrument for that track. NES/Game Boy/SNES have no per-note renderer (a register log, not a sequence) — each track is one hardware voice, so the tap instead slices that exact moment out of the track's own already-rendered sound, release tail and all. A brand-new note you've just placed (nothing was rendered where it now sits), a drum hit, or a track given an explicit voice all still play the synth. Hearing one note at a time is the point of analysis mode.
Status line (footer)
The footer's own first line (2026-09-30: its own row, Chord? at its right end when there's a selection to reveal in Normal mode — nothing else shares the row with it any more). Tap it to read it in full, even a long one: it wraps to two lines before it has to clip at all, and tapping opens the whole message in a sheet — nothing it says is ever lost past an ellipsis. A message that also offers a copy (a chord name, a note's detail) keeps its own tap-to-copy instead, unchanged.
Copy the pitch list
When the lasso strip lists selected pitches, tap the text (or the ⧉ copy chip) to copy them comma-separated — after "Chord?", the chord name comes along too.
Lasso
On your own songs the Lasso button sits at the left of Select / Pencil / Erase; on songs you can only read, it stays in the footer. Toggle on, then drag a box over notes (works in all views). Boxes ADD to the selection — draw as many as you need. Tap any note to toggle it in or out (surgical removal of a pedal or neighbor); tap empty space to clear. ANNOTATIONS

Attached notes on ANY annotation
Every typed annotation — key, meter, tempo, section, chord, loop — can carry a text note: in its editor, whatever you write in the note box below the value rides along (sections have a dedicated label field, so the note box is purely the note — and key, meter, tempo, loop, and chop all show the note box too). The ✱ marker in bands and ☰ Notes says one is there. This is where the DOUBT lives — "whole-tone material, no conventional key" can sit on a key: B♭? and make the open question findable later.
☰ Notes ▴
Tap the footer's ☰ Notes ▴ for a drop-up: Hide notes strip / Show notes strip (the strip above the footer that shows the note at the playhead — same as View ▾ → Panels → Notes strip), and + New note writes a note anchored at the cursor's beat — or tap Speak and dictate it; fill "to bar/beat" to span a range; the ⊙ highlight toggle in the note strip shades the current note's span in the timeline. ☰ All notes lists every annotation in the song, grouped by type — key, meter, sections, chords, loop, text notes; tap a row to edit or delete it, each group's + adds one of that type; changes to synced notes need a Sync to become permanent. Shortcut: double-tap a section or chord band in the ruler to open that annotation directly, same as ☰ All notes' own row.
Ruler drag
Each song remembers its ruler selection on this device, so after the app restarts Play loops the same range. A tap on the ruler just places the cursor, on the nearest 8th (drag the strip below it for finer spots) — even a slightly wobbly tap; only a drag of more than about a finger-width selects. Drag along the bar ruler to select a range — + Note pre-fills it, and Play cycles over it, Logic-style: playback starts from the cycle's top every time and loops just that span (any loop: annotation is ignored while it's armed). Bar lines are magnetic: land within a finger's width of a bar line and the edge snaps TO the bar (measured in screen pixels, so it works at every zoom); away from bar lines, edges snap to 16ths — zoom in when you want fine edges. Tapping or dragging the ruler never clears your note selection — select notes, set the range, audition, all without re-lassoing. Only a DRAG arms the cycle — tapping a section or chord band still selects its range for + Note, without changing playback. Grab either edge of the highlight and drag to stretch or shrink it in either direction (bar-magnetic, stays armed). When sections nest, a ▸ chevron at the ruler's left edge cycles how many levels show — fold away a drum-keying sub-label and look at just your form; folded levels still drive the Drummer (device-side view only, per song). Tapping the ruler parks the highlight (it dims but survives); tap inside the dimmed span to re-arm it without redrawing, or drag a new span to replace it. While a cycle is armed, Back-to-start returns to the cycle's start instead of bar 1. The playhead's triangle handle under the ruler is draggable in any mode. On any song, drag a section or chord band by its edge (in its ruler lane) to move that boundary — snaps to 16ths, saves like any other edit, and undo undoes it. Bands are your annotations, not the music, so this works on captures and FF1 songs too; the .mid is never touched.
Playhead strip
Tap the thin strip under the ruler to move the cursor without touching your cycle — a tap lands on the nearest 8th; drag to scrub, which steps in 32nds (or the triplet/custom grid while one is active) for the in-between spots. It sits right above the notes (Roll, Tracks, and Score alike), with its own faint beat lines matching the meter, bar lines stronger. Unlike the ruler above it, a tap here never parks, clears, or re-arms your ruler selection — it just moves the cursor, even over an armed or parked cycle. While playing, a tap plays on from exactly where you tapped: inside the cycle it keeps cycling; outside it, playback runs straight on and the cycle takes over again on the next ▶. Lifting a scrub while playing does the same.
Gold flags
Existing annotations. Tap one to jump there and read it in the strip above the footer. They also appear as subtitles during playback.
Loop points
Some songs loop back past an intro (not to bar 1). When you discover one, write a note whose text is loop: B.Q (e.g. "loop: 2.1") — the note's anchor is the jump point: when playback reaches it, it returns to B.Q. If the anchor sits at/before the target, the jump happens at the song end instead.
Sections
Colored bands in the ruler (A, B…). Make one: select a range, + Note, tick "section", give it a short label. Nest them by containment. Tap a band to select its whole range. Sections and chords each get their OWN row group (sections above, chords below), so a section and a chord covering the same bars never fight for a lane.
Chords
Chord bands — like sections, but typed. Select a range, + Note, "Chord", then tap chips (root · ♭♮♯ · quality · extensions · /bass) or type the symbol. Bare root = major, m = minor (Gm). The quality row picks ONE (maj/m/dim/aug/sus2/sus4/5); the extensions row STACKS — tap 7 and add9 on top of m for Cm7add9, tap again to remove one. Anything the chips can't spell, type into the box — the label is free text and typing always wins. Same label = same color, so a recurring chord is spottable at a glance. Add an optional text note to a chord — it shows as ✱ on the band. On YOUR songs, moving a selection of EVERY note in the song takes the entire annotation layer with it — sections, chords, the loop point and its target — with chord and key labels transposing on vertical moves (global facts like meter and tempo keep their bar-1 anchor); that's how you cut an intro and slide everything left without orphaning your analysis. Moving a selection that carries one band's every note takes that band along (position slides, label transposes — Cm dragged up two semitones becomes Dm), When YOU ask for it — the Check labels button in ☰ Notes' CHORDS group — the app compares each label against what sounds in its span and flags mismatches (⚠ on the band, the reading in the list). It never volunteers this and never rewrites your labels; any note edit clears the flags. The check hears EVERY pitch sounding in the span, so passing tones and dense textures can read as "no standard chord match" — a flag is a nudge to listen, not a verdict.
No accidental duplicates
Re-labelling replaces, it doesn't stack. A key at a beat that already has one replaces it — but a key at 3.1 and a key at 3.3 are two different keys and both stand, so a mid-bar modulation keeps its real anchor. A chord band on the exact same span replaces whatever was there, whatever its label; a shorter band starting at the same beat is left alone. Text notes stack freely — several different thoughts at one anchor is the normal case — and only a repeat of the identical text at the identical anchor is dropped. Sections are untouched by this: nesting is by containment.
Chop
Trim a song without touching the file: put the cursor at the cut, + Note, "Chop", pick "everything before this beat" or "this beat to the end". The chopped part vanishes entirely and bars renumber (chop a 2-bar intro and old bar 3 becomes bar 1 — your annotations shift with it). Delete the chop in ☰ Notes to restore. Made for cleaning up freshly imported captures.

key: picker — now the key on the transport display

mode? (partial keys)
Same two dropdowns as the key picker above — tap the key on the transport display, or + Note, type Key. Know the tonic but not the mode yet? Check vs file
In ☰ Notes, the KEY and METER groups each carry a Check vs file button — on every song, capture or composition alike, tapping it never reveals anything by itself. It compares what YOU declared against the label some MIDI files carry on their own (a game rip's own meta, an export from another program) and reports one of: your answer matches, the file's label says something else, it matches for only part of the song, you haven't set an answer yet to compare, or this file carries no label of its own — file labels can be wrong (many programs default to C major / 4/4), so a difference is a nudge to listen again, not a correction. In Normal mode it also states the file's own value plainly and — for key — the note-census estimate, plus a one-tap Use the file's button (key: adopts it as a declared key: immediately; meter: opens the meter editor pre-filled with it, same re-bar confirmation as any other meter change). Edit row
On your own songs (never on captures) a dedicated row appears above the footer: Select / Pencil / Erase (tap the active tool again to turn it OFF — then dragging only pans, and no note can be grabbed by accident), durations 32nd–whole incl. dotted, plus 16· (dotted 16th) and 8T/16T triplets — picking a triplet also switches the snap grid to triplet steps, and picking 32nd switches it to 32nd steps (it also goes 32nd-fine on its own once the song CONTAINS 32nds) (Logic's grid-division trick: your 4/4 stays 4/4, entry just lands on thirds until you pick a straight duration again), p/mf/f velocity, the ♮♯♭ accidental segment in score view, and undo.
Record
On your own songs: tap the chip of the track you want to record onto, then Record beside Play arms the take — the Instrument panel opens, Record blinks red, the transport rolls (count-in applies), and every key you play lands on that track at the playhead — hold a key for a long note, slide across keys for runs — or play a REAL MIDI device (a Jamstik, a keyboard): the browser's MIDI input records with your actual velocities, chords included (Chrome/Edge on the computer; Safari in a browser has no Web MIDI). A MIDI keyboard works on the iPad app too — its WKWebView has no Web MIDI either, so the app ships its own native MIDI bridge instead (CoreMIDI under the hood); plug the keyboard in and it shows up here exactly like a computer's would, no browser needed. Recording keeps what you played (Logic/GarageBand/Cubasis convention): starts and durations land exactly where you played them, on- or off-grid, not snapped — Settings → Other → Snap while recording (default off) restores the old always-on-the-grid input for anyone who wants it. Either way, straighten a take afterward with Q Quantize (below) instead of fighting the grid while playing. Record again or ■ stops; the whole take is one undo step. Record also says what it sees in the status line: your MIDI inputs by name; no MIDI inputs found when nothing is plugged in or the browser can't see it (Chrome lists what it sees at chrome://settings/content/midiDevices); MIDI blocked when the permission prompt was dismissed — allow it from the icon in the address bar and reload; or no Web MIDI on Safari.
Pencil drag
In Pencil mode, tap places one grid-unit of note — or keep dragging and the note stretches under your finger, snapped to the duration grid. The duration picker is note value × modifier: pick 1/2/4/8/16/32 (whole through 32nd), then — (plain), · (dotted), or T (triplet) — every duration a staff can write, two taps. A tap lands the note in the CELL you touch: press anywhere in a gap and the note starts at that gap's gridline, no edge-hunting.
Drum chart (score view)
The kit renders as a real percussion staff at the BOTTOM of the score: percussion clef, positions are roles not pitches (kick in the bottom space, snare in the third, toms by size, hats above the top line), x-noteheads for hats and cymbals, stems up for hands and down for feet. Read-only for now — kit entry lives in the roll's drum lane; lasso and tap work on the chart like anywhere else.
Score entry
Pencil and Erase work on the engraved score too: tap a staff position and the note lands there — the stave you tap picks the track, the height picks the pitch (ledger lines included), and the key signature supplies sharps/flats automatically. The key/♮/♯/♭ segment overrides the signature when you want an accidental. Erase taps a notehead out.
Move
Select notes (lasso or tap one), then drag them — up/down transposes, left/right slides in time on a 16th-note grid (triplet steps while a T duration is active), and the whole selection moves together, so a chord moves as a chord. Works straight from lasso mode: start the drag on a selected note. Keyboard: arrows (Shift+↑↓ = octave).
Resize
Drag a selected note's right edge to change its length, or its left edge to move the start while the end stays put — every selected note adjusts by the same amount, so "play this chord half as long" is one gesture. Notes too small on screen to have edge zones are all move-handle — zoom in to resize them. Keyboard: Option+←→.
Copy
A real copy and a real paste: ⧉ copies whatever is lasso'd (or tapped) — and when the lasso box itself reaches up into the ruler over them, the chord bands, section bands and text notes it spans ride along, so a copied phrase pastes with its labels (a box that stays among the notes, or a tapped selection, copies notes only; chord labels transpose if Paste to… shifts the pitch; key, meter, tempo and track directives never copy) — Cut cuts (copies to the clipboard AND deletes — lasso'd annotations included — one undo restores all of it), 📋 pastes at the blue cursor and moves the cursor to the end of what landed, so the next 📋 (or ⌘V) chains straight on; Edit ▾ → Paste to… is the richer paste: the same clipboard, onto a track you pick, shifted by octaves and/or semitones — the bass line's exact rhythm onto pulse2 an octave up, or up a third for a harmony, in one go instead of paste, move, retrack — and the copy SURVIVES scrolling, changing selection, even changing tools, so "lasso bar 3, scroll to bar 16, paste" is exactly three gestures. ⌘C fills the same clipboard. Pasting and chord inserts never stack an identical note on an existing one. For stacks from older drafts, 🧹 Remove duplicate notes in the Move to track sheet sweeps the whole song (within each track; deliberate unisons BETWEEN tracks are always safe) — then SAVE, so a stale draft can't resurrect them. A chord progression is pencil one chord → ⧉ → 📋 at each cursor stop. Buttons that can't do anything right now are grayed — no selection grays copy/delete/split/join/move, an empty clipboard grays paste, empty histories gray Undo/Redo. With a keyboard there's also Option-drag (drags out an in-place copy) and ⌘C/⌘V.
Insert chord (♫)
Tap ♫ in the edit row: pick a root, a quality (maj, m, 7, maj7, m7, dim, sus… — triads insert three notes, sevenths four), an octave, and a duration (16th to whole, dotted included), then Insert — the whole chord lands at the blue cursor on the selected track, a matching chord band appears in the ruler, and the cursor walks forward one slot. Repeated inserts build a progression without closing the dialog; the inserted notes arrive selected, ready to nudge. The dialog's Progression tab holds a library of whole progressions organized by emotion — triumphant, yearning, ominous, grieving, and twenty more, in Roman numerals so they work anywhere: the tonic pre-fills from the song's declared key when there is one; pick octave and duration, tap a mood, and the entire progression lands one chord per slot with matching chord bands in the ruler, all selected, one undo step. Stretch or rearrange afterwards. Or type your own in the box above the list — i – VI – VII – V, hyphens or commas or spaces all fine, lowercase for minor chords, ♭/♯ (or b/#) in front, °/7/maj7/6 after — and pick the scale the numerals count against: minor scale makes VI and VII the natural-minor degrees (in E: C and D), major scale reads them the textbook way (C♯ and D♯, so write ♭VI there). A minor key at the cursor pre-selects minor. Full chords land; erase tones to leave the arpeggio you want. The same mood list is also behind the Progressions button in the ◯5 dialog, for browsing while analyzing.
Transpose
Lasso notes → ⇅ (behind More, or Edit ▾): half/whole-step chromatic buttons, octave jumps (▲/▼ 8va), plus in key ▲/▼: every note moves one SCALE DEGREE of the declared key — the "whole step up that stays in the key," where some notes move 1 and some move 2. Out-of-scale notes slide chromatically; no declared key = chromatic with a warning. For a WHOLE track, open its voice & color menu (tap the selected chip again) — the octave ▼/▲ 8va row shifts every note on that track, one tap per octave, each tap one undo step. "What if the bass lived three octaves up?" is three taps, no lassoing, no muting. Notes at the range edge stay put; the drum track never transposes (kit pitches are instruments, not notes).
Move to track
Select notes and tap Move to track, then pick a track — the notes switch instrument, keeping their time and pitch (play a passage into one voice, then deal melody, harmony, and bass out to pulse1/pulse2/triangle). When the selection spans several tracks (doubled unisons), a move only row lets you move just one track's copies and leave the others — or solo a track BEFORE lassoing: hidden tracks can't be selected at all.
Drum fill (🥁)
Tap 🥁: a one-bar step grid for kick, snare, and hat, sized to your meter (8ths or 16ths), pre-seeded with a standard backbeat. Toggle cells, set the range — bar typed, beat and 16th-subdivision (· e & a) picked from dropdowns, pre-filled from the cursor, so drums can enter at bar 2 beat 4 exactly — and Fill: the pattern repeats from that point on the drums track (created automatically if the song has none), skipping hits that already exist. One undo undoes the whole fill; embellish afterwards with the pencil in the kit lane.
Split
Select notes and tap Split. If the blue cursor sits inside them (tap the ruler to place it), each selected note the cursor crosses splits at that exact spot; if the cursor is elsewhere, each selected note splits in half.
Join
Select two or more notes on the same pitch and tap Join — they merge into one note spanning first start to last end (each pitch merges separately, so a lassoed pair of chords joins into one longer chord).
Unsaved dot
A gold ● after the title means the song has edits that haven't been published — it appears the moment you change anything and clears when Publish sheet succeeds (the Save sheet's title says which state you're in, too).
Drummer
The Drummer button beside 🥁 in the edit row (also Edit ▾ → Drummer…) generates a kit part for a bar range (prefilled from the ruler selection if one is armed, else the section under the cursor). It reads the structure YOU declared: a fixed backbeat skeleton (kick on 1, meter-aware snares) that seeds never move, hats whose loudness always stays under the snare, kicks that follow the bass track's offbeats, accents on chord-change downbeats, a snare on the bass's LONG notes (the agogic accent), fills from a small vocabulary before section boundaries and the loop target (crash on the arrival), and SILENCE in breaks — a bar where only the bass plays, or a section labeled "break", gets no drums at all. Each take REPLACES the range's kit notes and is exactly one undo step, so your hand-placed drums come back with one undo. Drummer again rerolls; the take chips replay any earlier take exactly (seed, energy, and range all remembered). Five knobs, Logic's split: busy (1–5) is density — hat subdivisions, ghosts, how eagerly kicks chase the bass; hard (1–5) is loudness — one uniform velocity shift across the whole kit, hats never dropping back below audible; fills (off–5) alone decides how often fills fire and how big (1–2 the quiet vocabulary, 4–5 runs/tom-drops/the full-bar buildup); follow picks what the kick listens to — any track, by name (its offbeat onsets and long notes, probabilistic; defaults to the detected bass) · chords (a kick exactly on every DECLARED chord change, deterministic, capped 4/bar) · off (skeleton and fills only); feel sets the backbeat rate — half (one big snare mid-bar, thinner hats: the slow-heavy read) · double (kick every beat, snare every offbeat 8th: the skank/D-beat read — bass-follow stands down, every slot is owned). The parts chips scope a reroll — kick, snare, hats, and fills (a role, not a pitch: the whole fill-and-crash layer at your section boundaries, snare runs and tom drops included). Toggle any combination: all four = the normal full roll; "I love these snares, reroll just the kick" = tap snare and hats and fills off; fills alone rerolls just the boundary bars (with fills set to off, that STRIPS the fills and lays plain groove — a de-fill). With the fills chip off the fills knob dims (nothing to control) and kept pieces stay byte-identical, hats capping under your real snares. Take chips now show their recipe (busy/hard/fills, ½ or 2× for feel, part initials when scoped) and still replay exactly. Layout: busy and hard are 1–5 segment rows (how much / how loud), fills off–5 and feel sit below, follow and parts under those — the long explanation you used to scroll past lives here in Help now. Two more rules: sections sharing an EXACT label share their groove — label two spans "A1" and the drums restate bar-for-bar (fills and crashes still vary: a fill is commentary on what comes next), so the same-label-same-color convention now also means same-drums; and at fills 4–5 the vocabulary opens its metal tier — a 16th-rate tom run down the kit, a full-bar crash-in kit fall, and a double-kick burst — weighted so big fills dominate the top of the knob.

Velocity
The vol slider in the edit row (1–127, the number beside it shows the value) sets the pencil's loudness — and with notes selected in Select mode, dragging it adjusts ALL of them live, brightness tracking the drag, committing one undo step when you let go. Tap a selection (or a single note) and the slider jumps to its current velocity — and when every selected note shares one velocity, the selection readout says so ("… 6 notes · vel 80").
Delete
Tap Delete in the edit row — every selected note goes at once. Delete key does the same.
Divide
Select notes, tap Divide, pick N (2–7): each note becomes N equal notes — pitch, velocity, and total span unchanged. This is how triplets happen: 3 on a half note = quarter-note triplets (the 1 · 1.667 · 2.333 placement no grid offers), 3 on a quarter = eighth triplets, 6 on a held two-beat note = a run of six. The pieces are free notes — drag them anywhere after.
Remove duplicate notes
Edit ▾ → Remove duplicate notes deletes notes stacked exactly on top of another on the same track (same start, same pitch) — you only ever hear one of them. The longer one stays; the status line says how many went, and one undo brings them back.
Quantize (Q)
Select notes, tap Q Quantize (Edit ▾ → Quantize…, or the Q key) and pick a strength — 100% snaps each note's start exactly onto the current grid (the same grid Move/Pencil use: 16ths, triplet steps with a T duration active, or 32nds with 32nd picked or once the song has any); 75%/50% moves it only partway there, a soft nudge for a take that's close but not glued down. Also quantize note ends additionally snaps each note's END and resizes to match — off by default, so a raw take's durations stay as played and only the onsets straighten. This is Logic's Quantize command: it acts on a selection AFTER the fact, undoably (one undo step for the whole batch) — recording itself keeps what you played (see Record); Quantize is how you straighten it out when you want to.
Undo
The edit toolbar always starts with undo, redo, cut, copy, paste and delete, then ⋯ (transpose, chords, Drummer, Bassist, divide, join, split), and Select / Pencil / Erase with Pencil's note values sit on their own row below — so neither row moves when ⋯ opens. Every gesture above — move, resize, copy, paste, delete, divide — is exactly one undo step, and so is every track change: voice, color, volume, pan, M / S / H. Keyboard: ⌘Z undoes, ⇧⌘Z (or ⌘Y) redoes, when you're not typing in a box. Everything that adds or removes notes is one step — pencil, erase, paste, split, join, chord and progression inserts (bands included), a recorded take, Drummer and Bassist takes — and so is adding or deleting a track: ✕ Delete track is one undo away, and a kit or bass track a generator created leaves with its take.

Import…
File → Import… opens the import hub: one screen, one section per format Night Roll reads, each saying exactly what it needs with its own Choose files… (one shared picker underneath — a file lands in whichever section's byte-sniff it matches, whichever section you tapped from); a drop target in the hub takes dragged files too. MIDI (.mid, .midi, .smf, .kar, even RIFF-wrapped .rmi — multi-select capable): ask where they belong — Keep local (this-device draft, annotations never sync) or Create album — one or many MIDIs become an album folder under drafts, audition/rename/✕ like a chip capture, and ⇪ Commit publishes them to the songs repo so annotations sync everywhere (commit rewrites the .mid as notes+tempo+meter — foreign CCs/programs are not preserved). NES: the .nsf, plus its .m3u if the rip has one (track names) — an NSF that needs an expansion sound chip (VRC6, VRC7, FDS, MMC5, Namco 163, Sunsoft 5B) is refused by name ("expansion sound chip <names> not supported") — the NES pipeline captures only the 2A03, and those songs keep their lead voices on the extra chip. Game Boy: the .gbs, plus its .m3u, same rule. Super NES: every .spc of the album, picked together — tagged lengths, so the loop scan is skipped. Genesis: .vgm/.vgz — synth voices only, no console-audio render yet. PlayStation: every .minipsf plus the one .psflib, picked together — reads Sony's own SEQ/VAB driver and Square's AKAO (Final Fantasy VII/VIII/IX, Chrono Cross); both play the console's own audio. PlayStation 2: every .minipsf2/.psf2 plus the one .psf2lib, picked together — reads Sony's stock driver (SQ/HD/BD) and Square Enix's own (BGM/WD — Final Fantasy X); both play the console's own audio. A PS2 set that's only streamed audio (Ico, XIII) is refused: "this is streamed audio, not note data — Night Roll reads sequence data (notes), not pre-rendered streams". Nintendo 64: every .miniusf plus the one .usflib. For NES, Game Boy, PlayStation, PlayStation 2 and Nintendo 64: a playlist (.m3u) picked on its own, later, names an open song's album (or, mid-capture, renames an already-open session's tracks). Every chip pick opens the capture panel: the same pipeline that dumped the FF1 album runs the track — loop detected and trimmed, tempo grid-fitted, the hardware loop point recorded as a loop: annotation (the capture window auto-doubles, 75 → 150 → 300s, when no loop fits) — and lands as a LOCAL draft under an album named for the game; audition and rename each one, ⇪ Commit a track or the whole album — it keeps going if you leave the menu, and it all keeps running in the background (Jobs) if you close the panel too — File → Publish import still pushes every import capture across all folders at once. Chip audio is automatic: whenever the app can reach a song's NSF/GBS/etc. (the live import session, this device's cache, or the public archive), NES, Game Boy, PlayStation, PlayStation 2 and Nintendo 64 songs render through the console's own sound hardware; Genesis and Super NES play through synth voices for now. SoundFont: one .sf2 (a fan-made game font, a better piano, anything) — not tied to a song at all: it loads straight in, a copy stays on this device (works offline, no GitHub needed) and, with a game files & instruments repo configured, pushes to the archive too so your other devices can play it; files over 50 MB ask first (GitHub itself warns past 50 MB, refuses past 100). New song from a recording: one .wav/.mp3/.m4a/.aif/.flac becomes a brand-new song — Untitled N, 4/4 at 120 bpm with three empty note tracks waiting (Edit → Pencil to write against it; ♩ Tempo from this take reads the clip's real tempo whenever you're ready) — it lives on this device until Save.

Data locations
Night Roll is configured with WHERE its data lives (Sync → "Data locations ▾"): three rows — songs (.mid, album.json, catalog), analysis (.rollnotes + docs), and NSF (chip-audio source) — each with a read base URL (blank = this site; or any raw.githubusercontent.com/<owner>/<repo>/<branch> or local server) and an owner/repo write target. One fine-grained token, granted to every repo you write to, covers all commits; write errors name the repo they hit, and a 404 usually means the token hasn't been granted that repo. This is what lets another analyst point their own analysis repo at a shared songs corpus. Defaults: everything in this site's repo, NSFs from the public nsf-archive. In the iPad app "this site" is only the bundled starters, so reads default to the repo in Settings → GitHub (the same place Publish writes): your published songs, annotations and imports appear there once the repo is set; the starters come from the bundle either way.

∿ Audio tracks (recordings)
A recording — a guitar take, a vocal, a phone memo, a DAW bounce — as a track next to your MIDI voices. Tap the ＋∿ chip in the track bar (compositions and local drafts; File → Import… also recognizes audio files) and pick wav, aiff, mp3, or m4a. The clip lands at the cursor's bar as a new track named after the file, with the usual chip: M, S, color, fader, rename, ✕ Delete track. Leading silence is trimmed on arrival, so the take's FIRST SOUND sits on that bar (the status line says how much it trimmed). It plays in time with the song, loops with it (a clip longer than the notes extends the song's end), and is in the exported audio. Slow it down and the pitch stays put: at any speed but 100% the take is re-rendered (time-stretched, the way a slow-downer app does it) in the background — the lane says "⏳ preparing 50% (pitch kept)…" for a moment, then it plays in tune with your notes; a device toggle in the recording sheet turns that off for tape-style, slower = lower, like chip audio. Fine for guitar and voice down to about 40%; grainier below. Tracks view shows the waveform; tap the clip to select it (the status line says file, length, where its bytes are, and where it starts), tap again to play from its start, and in Select mode hold and drag to slide it in time (16th snap, one undo undoes; with no tool armed a drag pans, as with notes). Every other view shows a thin ∿ strip under the ruler marking where the recording plays. Pieces: a recording can be cut into pieces that move on their own. Split at cursor (the edit row's Cut, Edit ▾, or the recording sheet) cuts the selected piece where the play cursor is; trim by dragging a selected piece's left or right edge in Select (left trim keeps the sound where it is); Erase tap on a piece removes just that piece (the track stays); each piece drags separately. One undo undoes any of it. Tap the selected chip for the recording sheet (‹ prev / next › step between pieces): nudge starts by a bar, a beat, or a 16th, offset by 10 ms or 100 ms (how far into the file the piece starts — the last hair of alignment), ⇤ Align first sound (re-trims leading silence to the current anchor), ♩ Tempo from this take (reads the beat spacing of the piece — its waveform's onsets, autocorrelated over 40–240 BPM — and offers the tempo it hears plus half and double, with how strong the read is; tap one and it becomes the song's tempo at bar 1, one undo undoes; your notes keep their bar positions, so the grid moves to meet the take, which is the point; needs about four seconds of steady playing, and your own songs only — captures keep their measured tempo), ♩♩ Map the bars to this take (the other direction: the GRID bends to the recording — it finds the beats through the whole piece, groups them into bars by the meter, and shows what it found: how many bars, the tempo range, and where the first downbeat sits; Apply writes one tempo change per bar from the piece's bar onward so every bar line lands on a downbeat it heard, wobble and all; ◀ downbeat / downbeat ▶ shift which beat counts as bar 1 when it guessed wrong — the correction Logic's Smart Tempo asks for too; the piece must start on a bar line, and a first downbeat that isn't at the piece's start means a pickup: shift, or trim the piece to the downbeat first; one undo removes the whole map), Split at cursor, Remove piece, Replace file…, and ☐ someone else's recording: tick it for a band's track you play along with and it is never uploaded — GitHub removes such files on a rights holder's notice, and a public site is distribution. Storage: until you Save, the bytes live on this device only (the sheet says so; Safari can evict browser storage after a week away, so Save soon); Save writes them beside the song as <song>.audio/<file> — into your folder in folder mode, into the songs repo otherwise. Files over 20 MB get one question: store as 16-bit mono WAV (lossless for a mono source, half a stereo bounce) or import as-is. m4a/mp3 note: Safari and Chrome trim the encoder's lead-in differently, so millisecond alignment is honest only for WAV/AIFF. Not yet: recording from the mic, trimming or splitting a clip, looping a clip by itself, keeping pitch when slowing down, iPad/Safari playback of webm.

Chip stream (experimental)
File → Settings → Other → Chip stream, beside Debug log: Off renders a PlayStation/PlayStation 2 song's console audio whole before it plays. On streams it instead, a couple of seconds at a time, so a big song (FFX "Challenge") can't crash the page's memory holding the whole thing at once; any failure for a song falls back to the whole render automatically. Auto (the default since 2026-10-01) streams only a song that would otherwise have to downgrade quality (mono, or a lower sample rate) or refuse outright to fit this device's memory — a song that fits as-is plays the ordinary whole render either way. A device setting — the switch doesn't change what you hear, only how it gets there.

Publish
Your edits are kept on this device by themselves; Publish is the deliberate step that puts a song in the repo where other devices and other people can reach it. The Publish sheet (File → Publish… and More → SONG → Publish open the same door) It lists every song with anything pending on this device, the open song first: a line when its music is edited since publish, each unsynced annotation on its own line with a ✕ that discards that never-synced note from this device, and a line when chat messages are unsaved. AI
Talk to an AI tutor about what you're looking at. Tap AI in the top bar. Every message you send carries the song, your cursor, the lasso, your own annotations, and the notes of the bars in view (or the ruler-selected range), so "what's happening in bar 9?" means YOUR bar 9 — bars and beats are the ones on your ruler, in your declared meter. Say the word and it will also add, edit, delete, or publish an annotation — never on its own; ask it to change or take back the wrong one and it edits or deletes that exact annotation in place (never a duplicate left beside it), and asking it to publish runs the same Publish the footer button does. Ask can also write notes on your own songs when you ask it to — spell it out ("a C3 gallop on the triangle in bar 5" means an eighth note plus two sixteenths, not the word "gallop") and it lands at once as one undo step; it never volunteers a note you didn't dictate. Ask can repeat bars: "repeat bars 5–6 after bar 6" copies them and moves the rest later, on every track, as one undo step.
House rules
🎓 Learning mode (Settings → Other): hints and direction first — it confirms or refines a guess you've made, and tells you outright only when you insist or say you give up; general theory questions it answers directly; it never reveals a key you haven't set. Normal mode: it answers music questions directly — keys, chords, cadences, form — and says how sure it is; an estimated key is named as an estimate, not a fact. Either mode, it never annotates on its own initiative or answers a question you didn't ask.

Jobs

New since your last message

What Claude Code is doing now

Update countdown

Backups on your Mac
On the Claude Code bridge, every edit to one of your own songs (a composition or a local draft) is also copied to the Mac a few seconds after you stop typing — off this device entirely, same content Publish would push. It's a safety net, not something you manage: nothing in the app reads or restores from it, and a Mac that can't be reached just means the copy waits for next time (it never blocks or interrupts an edit).

Terminal tab
Two pickers at its top choose the model the terminal gives its advisors (read-only reviews) and its builders (the agents that write code) — Opus, Sonnet, Haiku or Fable; the terminal session's own model is set at the Mac (/model). The chat is part of the song
The conversation is kept per song, whole, and it is part of the song's save: File → Publish appends everything since the last publish to <song>.ask.md beside the song (your session log — hand it to a code session later), the ● after the song title lights while chat is unsaved, and the Publish sheet lists it. Session usage and Compact
On the Claude Code bridge, a small line under AI's tab strip says "N turns · ~Nk tokens · $N.NN" for the chat you're in (♪ this song or Ask — not Terminal, which has no session of its own), refreshed after every reply and whenever you switch tabs; past 40 turns it adds "— long, Compact saves tokens". AI setup, step by step
Everything below runs on a Mac (or any computer) you own; the iPad then reaches it over your private Tailscale network.
LM Studio: load a model, then start its server with CORS on — Developer tab → Start Server, and in Server settings turn on Enable CORS (or in Terminal: lms server start --cors; this does not survive a reboot unless LM Studio itself starts at login). Its address is http://localhost:1234.
Ollama: it must allow the app's origin — quit Ollama, run launchctl setenv OLLAMA_ORIGINS "*", start Ollama again. Its address is http://localhost:11434.
From an iPad (it can only talk to https): install Tailscale on the Mac and the iPad, signed in to the same account; in the Tailscale admin console → DNS turn on MagicDNS and HTTPS Certificates; then on the Mac tailscale serve --bg 1234 (approve Serve once from the link it prints). The iPad's address is then https://<mac-name>.<tailnet>.ts.net. Undo with tailscale serve --https=443 off.
The Claude Code bridge (needed for Claude Code, the Terminal tab, screenshots and Backups on your Mac): in the Night Roll folder run npm run bridge — or keep it running across reboots with sh tools/launchd/install.sh --claude full --upstream lmstudio=http://localhost:1234 (--uninstall removes it). It listens on port 8787; expose it to the iPad with tailscale serve --bg --set-path /claude 8787 and set the iPad's Settings → AI address to https://<mac-name>.<tailnet>.ts.net/claude. It also lists LM Studio and Ollama models when they're running. Add --token <secret> to lock it and put the same secret in Settings → AI → API key.
Then Settings → AI → Test: it lists the models it can reach, or says exactly what's wrong (server off, CORS off, http from an https page, no answer).
Where the model runs
File → Settings… → AI model. In this browser: pick a small model (0.4–4 GB), the first Ask downloads it once and it runs on this device's GPU, nothing leaves the device; Test checks WebGPU and whether it's downloaded. On a server: the URL of an OpenAI-compatible server — LM Studio or Ollama on this computer (http://localhost:1234) or on another machine on your network — plus an optional API key; Test lists the server's models, picks one (your last pick if the server still has it), saves, and names exactly what's wrong when it can't (server off, CORS not enabled, https page talking to an http server, no answer in 8 s). On an iPad the server must be https (Tailscale Serve). The first time you point it at a machine other than this one, it asks once before sending your notes there.
Settings save themselves
Every Settings field saves itself the moment you leave it — there is no Save button and closing never loses anything.
Asking it to act
"put an F#m chord annotation on 21.1", "mark bars 6–12 as section A", "set a tempo of 192 at bar 6" — it writes exactly that annotation (unsynced, with a ✕ in the Publish sheet like your own). "compare this to ambush" makes it read that song's notes and annotations from the repo.
